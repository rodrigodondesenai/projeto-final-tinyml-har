# Checklist da entrega final

Requisitos informados para a entrega: apresentação em slides e/ou código,
vídeo com demonstração, repositório GitHub público seguindo Git Flow e commits
de todos os integrantes. Devem ser enviados o PDF da apresentação e um arquivo
`.txt` com o link do repositório público.

| Item | Situação atual | Ação necessária |
|---|---|---|
| Repositório GitHub público | Concluído | Link: `https://github.com/rodrigodondesenai/projeto-final-tinyml-har` |
| Git Flow | Parcialmente concluído | `main` e `develop` existem. As próximas alterações devem usar `feature/*` e Pull Request para `develop`. |
| Commits de todos os integrantes | Pendente | Gabriel e Renan precisam fazer contribuições reais a partir de suas contas GitHub e enviar seus próprios commits. |
| Slides em PDF | Pendente | Criar a apresentação a partir de `docs/guia_apresentacao.md` e exportá-la para PDF. |
| Vídeo de demonstração | Pendente | Gravar a execução REPLAY no Wokwi, mostrando `REPLAY_SUMMARY passed=6 total=6 status=PASS`, e explicar brevemente o resultado. |
| Arquivo `.txt` com o link | Preparado | `entrega/link-repositorio.txt` deve ser enviado junto ao PDF. |

## Contribuições do grupo

Cada integrante deve usar a própria conta GitHub. Após aceitar o convite como
colaborador, a pessoa deve criar uma branch a partir de `develop`, realizar uma
alteração que tenha feito ou revisado e abrir Pull Request. Exemplos adequados:

- Gabriel: revisar ou complementar slides, roteiro, resultados ou documentação;
- Renan: revisar o vídeo, a demonstração, a documentação ou os testes;
- Rodrigo: integrar as Pull Requests e preparar a versão de entrega.

Não crie commits em nome de outra pessoa. O GitHub atribui a contribuição à
conta do autor quando o e-mail configurado no Git corresponde a essa conta.

## Pacote para envio

Envie na plataforma da disciplina:

1. o PDF da apresentação;
2. o vídeo de demonstração, no formato ou link aceito pela plataforma;
3. o arquivo `entrega/link-repositorio.txt`.
